밝밤) 6월 1일 ~ 6월 7일 패치

06월 01일

일부 시작 지점에서 게임 불러오기 때 바로 튕기던 문제 수정

• 판자 친 시작 지점 관련 변경은 일단 이전 상태로 되돌림



CVD 장치로 다이아몬드 코팅한 근접무기에 방어구 관통이 붙음

• 베기/찌르기 피해의 35% + 10만큼 관통 추가

• 생체공학 무기는 피해의 50%만큼 관통 추가

• 야생 블랙옵스 생체병도 단분자검 설정에 맞게 관통 공격을 함



구급상자가 일반/고급으로 나뉨

• 일반 구급상자는 붕대, 거즈, 소독제, 의료용 테이프, 책자 위주

• 고급 구급상자는 기존 구급상자에 있던 추가 물품을 들고 나옴

• 기존 구급상자 스폰 일부가 고급 구급상자로 바뀜



응급처치 물품 밸런스 조정

• 식염수는 안약 대신 깊은 물린 상처를 50% 확률로 처치

• 지혈제 성공률 90% → 99%

• 임시 붕대 성공률 90% → 80%

• 솜뭉치 효과 75% → 50%

• 임시 소독제, 타임 오일, 부들 젤리는 성공률 80%로 통일

• 식염수로 식염수 안약을 만드는 제작법 추가



군 의무병 시작 직업 추가

• 응급처치 중심 스킬과 RX12 같은 드문 의료품을 들고 시작함



의료 앰풀과 스팀팩 모듈 제작법 추가

• 시험관, 식염수, 의료 재료, 나노물질이 필요함

• 기밀 화학 참고서와 리브텍 설계 바인더에서 배움



무작위 무기와 생존자 장비를 받는 도박형 시작 직업 추가



강철 참호 갑옷과 헬름이 생존자 좀비와 일부 도적 장비에 추가됨

• 스폰 비중은 대응되는 고철 갑옷의 1/3 정도

• UDP 타일에서 고철 갑옷처럼 보이던 문제도 고유 스프라이트로 바뀜



강화 전기 모터가 초합금이 아니라 강철 재질이 됨

• 제작 후 분해해서 초합금을 무한히 얻는 꼼수 차단

• 수리와 분해 결과도 강철 기준으로 바뀜



새 줍기 메뉴에서 탄약 같은 충전식 아이템을 원하는 수량만큼 제대로 줍게 됨

• 무게/부피 표시도 실제 수량에 맞게 표시됨

• 한도를 넘겨 주우려 할 때 예전처럼 손에 들지 물어봄



06월 02일

스키 바지와 스키 재킷 제작법 추가

• 스키 바지는 재봉 5, 스키 재킷은 재봉 6 필요

• 털가죽 없이 겨울용 하의를 만들 수 있음



방풍 재킷 재질이 플라스틱에서 합성 직물로 바뀜

• 베기/타격 저항이 약간 좋아짐



물 위 보스 크라켄 추가

• 붙잡기, 끌어당기기, 원거리 능력을 쓰는 강력한 수상 적

• 작은 배로 덤비면 위험하고, 장갑과 무장을 갖춘 배로 싸우는 걸 전제로 함

• 처치 시 흑요석 눈을 드랍함

• 흑요석 눈은 손에 들면 투시 효과를 주지만 네더의 주목도 같이 받음



소리 처리 방식이 크게 바뀜

• 소리 크기가 데시벨 기준으로 계산됨

• 거리와 지형에 따라 소리가 줄어드는 방식이 바뀜

• 총성, 폭발음, 괴물/NPC의 소리 반응이 전보다 일관되게 동작함



난민센터 구 경비대 의사 임무에서 TCL 잔당을 공격해도 구 경비대 전체가 적대하지 않음

• 폭력으로 임무를 해결하면 TCL 잔당만 적대함



등대와 모래섬 아래 지형 수정

• 물속 암반 기둥이 다시 생김

• 등대 지하 계단 위치가 지상 계단과 맞게 바뀜

• 지도에서 등대 지하가 이상한 아이콘으로 보이던 문제 수정



06월 03일

디럭스 밀크셰이크와 강력 항생제의 건강 페널티 조정

• 디럭스 밀크셰이크 -6 → -3

• 강력 항생제는 -5로 조정



방풍 재킷 제작법 추가

• 합성 직물 조각 9개 필요

• 재봉 3이면 자동 습득, 책이 있으면 재봉 2로 제작 가능



자기 전이 주문이 선택한 전이문 위치가 아니라 북서쪽 24칸에 떨어뜨리던 문제 수정



Aftershock 제작 장비 3종을 기지 전력에 연결해 설치할 수 있음

• 조리 리그, 키친마스터 조리 버디, 메탈마스터 단조 버디

• 배터리 대신 건물 전력으로 사용 가능



소이 파편 효과 추가

• 25mm HEI는 작은 파편을 뿌리고, 파편에 맞은 적에게 불이 붙을 수 있음

• 대신 기존처럼 바닥에 불길을 까는 효과는 빠짐

• 라우포스탄은 폭발 반경 5 → 2로 줄고, 반경 5 파편 효과가 추가됨



옷을 더 따뜻하게 입었는데 오히려 체온이 급락하던 문제 수정

• 얼음 연구소처럼 극한 환경에서 체온 변화가 더 부드럽게 처리됨



06월 04일

짙은 연기 같은 시야 차단 필드가 사라져도 타일이 계속 안 보이던 문제 수정

• 짙은 연기가 일반 연기로 약해지거나 흩어지면 바로 시야가 돌아옴



전기 엔진 소음 감소

• 배터리로 도는 엔진은 소음이 10% 수준으로 줄어듦

• 차량 속도 때문에 소음이 과하게 커지던 계산 제거

• 음속을 넘는 차량은 소닉붐으로 180dB 소리를 냄



40mm 산탄/슬러그 사거리 증가

• 40x46mm 산탄/플레셰트 10~12 → 24

• 40x46mm 슬러그 36

• 40x53mm 산탄/플레셰트 30, 슬러그 45



기침약 복용 시 빠져 있던 기분 보정 적용



놋쇠 재질 아이템을 수리하고 분해할 수 있음

• 청동 수리 도구로 놋쇠도 수리 가능

• 금속 절단 도구로 놋쇠 회수 가능



보이지 않는 타일에서 “탄환이 X에 맞았다” 메시지가 뜨던 문제 수정

• 투시 없이 벽 너머 전투 상황을 메시지로 알 수 없게 됨



속도 계산 때문에 투척물이나 조용한 원거리 무기가 말도 안 되게 큰 소리를 내던 문제 수정



일부 전리품/시작 장비 오류 수정

• 플린트락 장총에 맞지 않는 산탄이 같이 나오던 문제 수정

• Aftershock 일부 장비에 맞지 않는 플루토늄 배터리가 들어가던 문제 수정

• Arcana 야생 수호자 시작 보석 누락 수정



06월 05일



용숨결 산탄이 원뿔 범위에 피해만 주고 불길을 남기지 않던 문제 수정

• 이제 의도대로 범위 안에 화염 흔적이 생김



40x46mm/40x53mm 유탄 탄피가 같은 구경이면 하나로 취급됨

• 기절탄/최루탄에서 나온 탄피도 같은 구경 재장전에 재사용 가능

• 40x46mm 산탄, 슬러그, 플레셰트, 임시 고폭탄 제작이 탄피 종류 때문에 막히지 않음

• 기존 저장의 옛 탄피도 새 탄피로 바뀜



일부 마약 효과 시간이 길어짐

• 코카인 5시간

• 크랙 5시간

• 블런트 2시간

• 조인트/마리화나 1.5시간



구덩이 안에서 옆 구덩이로 이동할 때 반복 탈출 판정/낙하 피해가 뜨지 않음

• 같은 구덩이끼리 이동하면 안전하게 이동

• 다른 위험한 구덩이로 들어갈 때는 기존처럼 위험함



수리 메뉴에서 이미 보강된 아이템은 숨김

• 단, 몸에 안 맞는 아이템은 수선할 수 있으면 계속 표시됨



엔진 시동 시 무조건 백파이어가 나던 문제 수정

• 백파이어 소리도 엔진 출력에 따라 과하게 커지지 않게 줄어듦



아틀라틀 화살통 설명이 실제 수용량에 맞게 바뀜

• 15개가 아니라 실제로 들어가는 10개 기준



전술 헤드셋을 파워아머와 같이 착용할 수 있음



자동 줍기 조건에 더 많은 필터를 쓸 수 있음

• 분류, 재질, 품질, 메모, 책이 가르치는 스킬 기준으로 필터 가능

• 예: `c:workshop tools`로 작업장 도구 분류 줍기



차량이 위아래에서 날아오는 총탄을 더 제대로 막음

• 지붕 있는 차량 안에 있으면 위에서 쏘는 공격이 사람 대신 차량을 맞힘

• 아래층 포탑이 헬기 안의 플레이어를 그대로 쏘던 문제 완화



차량 부품 같은 겹쳐지는 일반 아이템도 손상/수리 가능

• 무적처럼 안 부서지던 일부 차량 부품 문제 수정



macOS 터미널판 DMG에 필요한 ncurses/formw 라이브러리가 같이 들어감

• Homebrew가 없는 맥에서도 실행 실패가 줄어듦



도시, 차량, 지도 생성, 소리 처리 중 나던 랜덤 튕김 여러 건 수정



06월 06일

현실 찢김을 닫는 기능이 기본 게임에 들어옴

• 별도 모드 없이 동작함



Hub 01 지하 접근 복구 및 지도 오류 수정

• 인터폰 임무 완료 후 지상 엘리베이터 사용 가능

• 율리시스 루크와 로보팩 NPC가 다시 등장

• 허가받은 상태면 Hub 포탑이 아군으로 유지됨

• 막힌 계단, 엘리베이터 조작부 겹침, 경비 무기 스폰 문제 수정

• 지하의 뜬금없는 금속 바닥, 잘못 놓인 가구, 어긋난 계단도 수정



기지 전력으로 쓰는 도구 가구 추가

• 전력 핫플레이트

• 전력 임시 밀봉기

• 전력 총기 수리 도구

• 총기 제작 키트에 탄피 성형 품질이 빠져 있던 문제도 수정

06월 07일

일부 학생 콘셉트 시작 직업에 고등학생 나이대가 적용됨

• 롤러블레이더, 스케이트보더, 청소년 비행자, 주니어 생존가, 피구 선수, 과학부원, A/V 동아리원



어린이 좀비를 죽여도 죄책감 사기가 깎이지 않음

• 불탄 어린이 좀비 등 변종도 포함



비활성 포탑 아이템 표시 수정

• 비활성 유탄 발사기 포탑 설명이 .50구경이 아니라 40x53mm 유탄으로 바뀜

• 비활성 .50구경 포탑에 타일이 붙음



일부 생체공학, 돌연변이원, 소프트웨어 아이템에 빠진 타일 지정 추가



호버크래프트 반발장치 제작 비용 꼼수 완화

• 포털 생성기 부피 500ml → 2500ml

• 나노제작기로 포털 생성기를 뽑아 반발장치를 만들 때 나노물질 비용이 80 → 200 수준으로 증가



차량 저장칸을 꽉 채울 때 detached pointer 오류가 나던 문제 수정

• 좌석에 블루베리 200개를 넣는 식의 과적도 제대로 처리됨



그래픽판 조명과 일부 시야 처리 방식 변경

• GPU 렌더러에서 성능 향상을 위한 기반 작업이 들어감

• 차량 카메라 시야가 더 일관되게 보임

• 색이 있는 조명 지원 추가



연구소 클로닝 배양조가 안의 물건을 바닥에 밀어내던 문제 수정

• 배양조 방의 변이 신체 부위가 바닥이 아니라 배양조 안에 들어감

• 배양조는 끌고 다닐 수 없게 바뀜



유물 저장/불러오기 오류 수정

• 무게, 가격, 부피 값이 꼬이던 문제 수정

• 범위 초과 오류 수정
