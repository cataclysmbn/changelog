밝밤) 6월 29일 ~ 7월 5일 패치

06월 29일

권총 FMJ 탄 관통력과 일부 피해가 내려감.

• 9mm FMJ는 기본 피해 25, .45 ACP FMJ는 30 기준으로 맞춰짐.

• .44 종이탄 피해 33→30, .38 스페셜 할로포인트 설명이 FMJ로 뜨던 문제 수정.

• 슬러그탄 피해도 00 산탄 기준에 맞게 다시 잡힘.



방탄복 수치가 크게 바뀜.

• 케블라 조끼는 9x19mm FMJ를 막을 정도가 된 대신 착용 방해 5→10.

• 드래곤스킨과 강철/초합금 MBR 조끼는 5.56x45mm, 세라믹/경강철 MBR 조끼는 7.62x51mm까지 막는 쪽으로 상향.

• 파워 아머와 RM13 방탄 수치도 탄약 기준에 맞게 올라감.

• 해당 장비를 입은 좀비들의 방탄도 같이 맞춰짐.



케블라 조끼도 사이즈 조절 개조를 쓸 수 있음.

• 기존 XL 케블라 조끼는 더 이상 새로 나오지 않음.



생존자 슈트 제작법이 케블라 조끼나 SWAT 방어구를 통째로 먹지 않음.

• 대부분 케블라 판을 쓰도록 바뀜.



수제 리볼버가 구경 변환킷을 단 채 .357 탄을 장전하고 스폰될 수 있던 문제 수정.

• 다른 수제 총처럼 시작 장전탄이 빠짐.



전투 의무병 시작 선택이 전투 공병과 겹치던 문제 수정.

• 일부 군 시나리오에 화염방사병 계열 시작 선택도 추가됨.



장비 효과 붙은 물건을 벗거나 버릴 때 효과 계산이 다시 됨.

• 변신 아이템이나 장비 효과 처리 뒤 게임이 튕길 수 있던 경우 수정.



06월 30일

비 오는 날 효과음이 한 번만 나오고 끊기던 문제 수정.

• 비소리가 계속 반복 재생됨.



도시 외곽에 교외 주택지가 생김.

• 숲 옆에 대형 아파트나 도심 블록이 바로 붙는 일이 줄어듦.

• 아파트는 도시 안쪽에 더 많이 나옴.



산성 좀비 진화가 민간인/군인 가지로 나뉨.

• 민간인 산성 좀비는 산성 박격포 좀비/스포너 좀비 쪽에서 끝남.

• 군인 좀비는 산성 저격수/지원 좀비를 거쳐 산성 저거너트로 감.



리브텍/후반 탄약과 산탄총 관통력이 새 방탄 수치에 맞게 올라감.

• 8x40, 5x50, 20x66, .277 탄이 세라믹판 방탄복 상대로도 피해를 내도록 바뀜.

• 리브텍 플레셰트/슬러그는 5.56급 방탄복 상대로 피해를 냄.

• 일반 00 산탄은 케블라 조끼에, 일반 플레셰트는 빈 MBR 조끼에 일부 피해를 냄.



둔기 무기 스킬 피해 배율 하향.

• 맨손은 그대로.

• 둔기 무기는 스킬 0에서 70%, 스킬 10에서 110%까지 오름.



TCL 연구소 특정 복도에서 지도 재생성 오류 팝업이 뜨던 문제 수정.



해골 진화가 다양해지고 해골 헐크가 늦게 늘어남.

• 기본 해골은 30% 확률로 해골 쇼커가 될 수 있음.

• 해골 브루트는 65% 해골 헐크, 35% 해골 마스터로 진화.

• 해골 브루트 진화 시간 기준이 12일→24일.



케블라 좀비가 새로 추가되고 기존 케블라 좀비는 케블라 브루트로 이름이 바뀜.

• 새 케블라 좀비는 군인 좀비와 비슷하지만 방탄은 드래곤스킨의 75% 정도.

• 완전한 5.56 방탄 브루트가 나오기 전 중간 단계 역할.



동료 NPC에게 잠자라고 명령할 수 있음.

• NPC가 피곤할 때 대화 메뉴에 수면 명령이 뜸.

• 바닥에서 자거나, 근처 벤치에 담요/베개가 있으면 그쪽에서 잠.



방어구 손상 계산이 바뀜.

• 피해가 몸까지 안 들어와도 큰 충격이면 방어구에 흠집이 날 수 있음.

• 대신 약한 관통 공격은 전보다 방어구를 덜 망가뜨림.

• 튼튼함(STURDY) 장비는 손상 회피가 더 좋아짐.



07월 01일

아음속탄이 소음기와 같이 쓸 때 더 조용해짐.

• 소음기 장착 시 아음속탄은 추가로 소음 15 감소.

• 아음속탄 설명에 소음기와 궁합이 좋다는 내용이 붙음.

• 소음기 설명도 효과가 어느 정도인지 더 알기 쉽게 바뀜.



움직이는 중에도 함정을 다시 발견함.

• 이전엔 기다릴 때만 주변 수색이 돌아서 함정 발견이 안 되던 문제 수정.



오트밀 칼로리와 가격 수정.

• 100g 300kcal 기준으로 열량이 올라감.

• 50g 귀리가 75달러로 찍히던 가격도 내려감.



먹기/마시기 메뉴에서 사용 후 커서가 엉뚱한 음식으로 튀던 문제 수정.

• 예: 메이플 시럽을 마신 뒤 주황 탄산음료로 커서가 넘어가던 문제.



군 드론 운용병 시작 직업 추가.

• 6점 직업. 마스터키 산탄총이 달린 M4, 00 산탄 총 34발, 비활성 맨핵 여러 개로 시작.

• 오토닥 전문가는 컴퓨터 4, 의료 레지던트 특성, 메스를 받음.



탄소섬유 제작/분해 결과가 더 자연스러워짐.

• 탄소섬유 총기/근접무기는 칼날·총열용 강철도 들어간 물건으로 판정됨.

• 탄소섬유판 분해로 재료가 불어나던 경우가 막힘.

• 탄소섬유 상부 리시버 무게 80g→240g, 탄소섬유 화물 운반칸 10kg→9kg.

• 전선 달린 탄소섬유 에어포일은 분해 가능.



애프터쇼크에서 거대 몸집 적응 변이가 직업 전용처럼 막혀 있던 문제 수정.

• 곰 혈청 등으로 거대 변이를 얻은 뒤 후속 적응 변이를 얻을 수 있음.



오염된 고기 건조 트레이가 건조 생선이 아니라 건조 오염육을 줌.

• 오염육을 식용 생선으로 바꿔 먹던 꼼수 막힘.



07월 02일

울타리/문 위 빈 공중으로 올라가 낙상 피해를 입는 행동 차단.

• '<'나 접사다리로 울타리 바로 위 허공에 올라가는 일이 없어짐.



좀비 기술자의 자석 끌어당김이 약해짐.

• 차량을 뚫고 끌어당기지 않음.

• 거리가 멀수록 끌어당기는 힘이 약해짐.



연구소 생성이 다시 늘어남.

• 오버맵마다 연구소가 최소 1개 나오도록 바뀜.

• 개미 연구소 비중은 낮아짐.

• 일반 연구소 지하 4층이 숨겨진 기차망과 다시 연결됨.

• 얼음 연구소와 연구소 탈출 시작 지점은 오버맵에서 계단 위치를 알아보기 쉬운 아이콘을 씀.



Hub 01 조명 회수 임무가 장소를 못 찾아 오류 내던 문제 수정.

• 무너진 탑 찾는 반경을 크게 넓힘.

• 여러 개면 가장 가까운 곳을 고름.



차량 상태 표시가 완전 무손상일 때 perfect로 따로 표시됨.

• like new는 이제 0~5% 가벼운 손상이 있는 상태로 보면 됨.



수납 방해도 계산이 딱딱한 수납공간부터 채운 것으로 바뀜.

• 상자형 배낭 같은 고정 방해도 수납이 남아 있으면 더플백/핸드백의 추가 방해도가 덜 붙음.

• 가방이 꽉 차면 전과 같은 최대 방해도.



커튼 달린 강화 플라스틱 창문이 커튼 없는 창문과 같은 파괴 난이도를 가짐.



EMP 폭탄 관련 멈춤/메모리 폭주 문제 수정.

• 군사 전초기지 탐조등 포탑 옆에서 EMP를 터뜨릴 때 게임이 멈추던 문제.

• 이어지는 폭발 처리 중 튕기거나 처치 판정이 꼬일 수 있던 경우도 막힘.



디버그 설정에 예전 방어구 손상 계산을 쓰는 옵션 추가.

• 새 손상 계산이 부담되면 이전 방식으로 돌릴 수 있음.



07월 03일

군용 재킷이 전투복 상의(army blouse)로 바뀌고 일반 옷층에 들어감.

• 방한 군복이나 방탄 조끼 같은 겉옷과 덜 겹침.

• 군 시작 직업들은 티셔츠 대신 언더셔츠를 받음.

• 군용 겨울 재킷 시작 직업도 전투복 상의를 같이 받음.



케이블 충전 CBM이 필요한 만큼만 전기를 뽑음.

• 예전엔 5J/턴짜리 CBM 하나 돌려도 Mk2 케이블 충전기가 매 턴 10kJ를 뽑고 대부분 버릴 수 있었음.

• 이제 1kJ 단위부터 최대 출력까지 필요한 만큼만 사용.

• UPS가 여러 개일 때 실제 꽂은 UPS에서 전기를 뽑음.



원거리 조준에서 '>'/'<'로 다른 Z층을 다시 수동 조준할 수 있음.



07월 04일



엎드리기 자세 추가.

• 엎드리면 BMG, ATGM 같은 거치형 총과 양각대 부착 총을 바닥에서 쏠 수 있음.

• 웅크리기보다 이동은 더 느리지만 더 조용함.

• 조준 속도와 명중에 이점이 있음.

• 쓰러지거나 잠잘 때 엎드린 상태가 되고, 상태가 끝나면 이전 자세로 돌아감.



우호 로봇이 적 위치를 찍어 줌.

• 우호 아이봇 등이 적에게 표식을 붙임.

• 드론 카메라 장비나 인포링크 CBM이 있으면 그 표식을 볼 수 있음.

• 파워 아머 헬멧, 컨트롤 노트북, 손목 제어 컴퓨터, RM13, 업그레이드 정찰 바이저 등이 해당 기능을 가짐.

• 경찰 아이봇의 지원 요청은 한 번만 작동함.



벤치/탁자류를 때려 뒤집은 뒤 다시 때려서 원상복귀되는 일이 없어짐.

• 벤치, 금속 벤치, 관광 테이블, 일반/커피 테이블은 처음엔 뒤집힐 수 있음.

• 뒤집힌 물건은 계속 때려도 반복해서 돌아가지 않음.



MP5SD 스폰과 내장 소음기 성능 조정.

• MP5SD가 나와야 할 곳에 일반 MP5 대신 제대로 스폰됨.

• MP5SD 내장 소음기는 일반 9mm FMJ/JHP를 아음속으로 낮추지만 +P탄은 못 낮춤.

• RM11B 내장 소음기는 탄속을 낮추지 않음.

• RM11B 소음 감소 성능도 살짝 내려갔지만 여전히 최고급.



타일판에서 일반 지도와 오버맵 확대 배율이 서로 꼬이던 문제 수정.

• 오버맵을 열면 저장해 둔 오버맵 배율로 보임.

• 닫으면 일반 화면 배율로 되돌아감.



삽질, 채굴, 벌목 같은 힘든 작업이 피로와 스태미나를 제대로 소모하고 운동 스킬을 올림.

• 수로 파기, 곡괭이질, 잭해머, 나무 베기, 통나무 자르기, 구덩이 메우기, 핸드 크랭크, 운동기구 훈련 등이 포함.



방탄 마스크 상향.

• 방탄 20→36으로 올라가 9mm까지 막는 설명에 맞게 됨.

• 생존자 마스크 제작에서 방탄 마스크 요구가 빠짐.



내가 낸 소리 때문에 내 작업이 끊기지 않음.

• 나무 베기/통나무 자르기 소리가 스스로 “큰 소리가 들렸습니다. 중단?” 창을 띄우던 문제 수정.

• 벽 뒤 좀비 발소리 같은 남이 낸 경고는 그대로 뜸.



07월 05일



안드로이드 실험판에서 WebP 시작/로딩 그림이 안 나오던 문제 수정.

• 시작 화면 그림이 정상 표시됨.



큰 호수 안에 외부 도로와 끊긴 섬 도시가 생김.

• 일반 도시처럼 도로와 건물이 깔림.

• 섬 모양은 도시 크기에 맞춰 잡힘.

• 접근용 선착장이 붙고, 큰 섬에는 공항 같은 땅 위 특수 장소도 나올 수 있음.



월드 옵션에 동물 번식/성장 속도 배율 추가.

• 0이면 계절 길이에 맞춰 자동 적용.

• 숫자를 넣으면 그 퍼센트로 번식 주기와 새끼 성장 시간이 늘거나 줄어듦.

• 비동물 몬스터 진화는 그대로.



차량 충격 흡수 장치를 장갑판과 같은 칸에 달 수 있음.

• 장갑판은 그 칸의 직접 피해를 막음.

• 충격 흡수 장치는 다른 칸 충돌 충격을 줄이는 역할이라 둘을 같이 설치 가능.
