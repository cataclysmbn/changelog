밝밤) 6월 22일 ~ 6월 28일 패치

06월 22일



군사 전초기지의 이성을 잃은 중장갑 바이오닉 특수부대원 강화형 추가

• 2주 뒤 근접형/샷건형, 6주 뒤 유탄형/퓨전 블래스터형이 스폰됨

• 외형이 달라서 어떤 무장인지 보고 구분 가능



건설 속도/스킬 보너스 효과 오류 수정

• 차량 작업에도 건설 속도 보너스가 적용됨

• 절단 스킬, 투시 보너스 계산 누락도 수정



총기형 아이템이 무조건 몸통을 덮지 않게 됨

• 총기 브리프케이스가 몸통 장비처럼 처리되지 않음



06월 23일

환각이 실제 물체에 영향을 주던 문제 수정

• 환각 괴물/NPC가 문 열기, 차 밀기, 전기장 생성, 차량 탑승, 아이템 소비를 하지 않음



접이식 불투명 차량 부품을 치워도 시야가 막혀 있던 문제 수정

• 천 보드 같은 부품을 접거나 부수면 바로 뒤가 보임



제작 총기의 구경별 중복품이 기본 총기 + 변환 키트 방식으로 바뀜

• 파이프 라이플, 수제 카빈, 루티 SMG 등이 대상

• 제작 총기 전용 개조 부품과 구경 변환 키트 추가



40mm 유탄 탄피, 40x53mm 변환 키트 타일 추가

• 케블라 조끼 타일도 파우치 없는 모습으로 바뀜



펫과 놀아준 뒤 오래 멈춰 있던 문제 수정



밀가루가 더 많이 나옴

• 상자 하나가 10개 고정이 아니라 5~40개 랜덤

• 식료품점/화물 상자의 새 밀가루 상자는 항상 가득 참



소름끼치는 인형(creepy doll) 타일이 시무룩한 얼굴로 보임



비행기가 이륙 직후 속도를 잃던 문제 수정

• 이륙 뒤에도 속도가 유지되고 상승/하강이 정상 작동함



06월 24일



경찰서 증거품 보관실 안쪽에 문 여는 레버 추가

• "포위됨" 시나리오에서 경찰서 시작을 골라도 안에 갇히지 않음



기억한 타일로도 마우스 자동이동이 가능해짐

• 지금 안 보이지만 전에 본 타일까지 경로선이 뜨고 이동 가능



수리 메뉴에서 필요한 재료 수를 미리 보여줌

• 목록과 수리 창에 쓸 수 있는 재료, 필요한 개수가 같이 표시됨



Skills Through Kills 모드를 한 번 켠 뒤 다른 월드의 스킬 경험치가 0이 되던 문제 수정



생존자 배낭이 생존자 MOLLE 팩으로 바뀜

• MOLLE 팩처럼 홀스터를 달 수 있음



지하철 시작 시나리오 "The Metro" 추가

• 도시 지하철 터널에서 혼자 시작하며 2점을 줌



체온 변이가 있을 때 냉난방 기능이 엉뚱한 온도로 맞춰지던 문제 수정



희귀 탄약/총기 스폰 조정

• 7.62x39mm 탄약이 경찰 증거품 보관함에서 아주 드물게 나옴

• 생존자 좀비는 약 9%, 베테랑 생존자 좀비는 약 25% 확률로 희귀 총기를 들 수 있음

• .50 BMG는 희귀 탄약 목록에서 빠지고, 드라코(Draco)는 희귀 소총 쪽에 들어감



난민센터에 엉뚱한 계단이 생기던 문제 수정



깔때기 분해로 플라스틱을 무한히 불리던 문제 수정

• 플라스틱 깔때기 무게가 제작 재료 3개분인 150g에 맞춰짐



06월 25일

캐릭터 생성에서 시나리오를 바꾸면 머리가 밀리던 문제 수정

• 선택한 헤어스타일과 색이 유지됨



전기 냉동고 음식이 맵을 떠난 뒤 얼어 있는데 썩어 있던 문제 수정

• 바닥 음식은 썩어도 냉동고 안 음식은 신선하게 남음



활성화한 바이오닉 스캐너 때문에 독서/제작 같은 긴 행동이 느려지던 문제 완화

• 제보 기준 독서 시간이 76초에서 22초 수준으로 줄어듦



연구소가 더 자주 나옴

• 얼음 연구소 확률이 1/3에서 1/2로 증가

• 일반 연구소도 오버맵마다 0~3개까지 나올 수 있음



여러 총기의 장전 상태 부피가 줄어듦

• 권총, SMG, AR 계열, 벨트 급탄 총기 등이 탄창을 꽂았을 때 덜 커짐



보이는 곳에서 난 소리에는 소리 표식이 뜨지 않게 됨

• 안 보이는 곳의 소리만 지도에 표시됨



일부 권총 무게/부피가 홀스터 기준에 맞게 조정됨

• 글록 20/21/22, S&W 모델 10, USP, 토러스 Judge 등이 대상



RM360이 희귀 SMG 스폰에 추가됨

• 총포상과 생존자 좀비에서 드물게 볼 수 있음



모신나강 소총에 개머리판 슬롯 추가

• 총열과 개머리판을 잘라 오브레즈(obrez)를 만들 수 있음



난민센터 배터리 충전 장치가 처음 생성될 때부터 제대로 작동함



맵 생성 중 차량이 겹치면 다시 파손 차량으로 처리됨



조준이 끝난 상태에서 대기키를 누르면 제대로 기다림



네크로폴리스와 타코마 공동체가 월드에 하나만 생성됨



마법 소리가 전반적으로 줄어듦

• 작은 주문까지 소리 190으로 나던 버그가 고쳐짐

• 주문 소리 상한이 150으로 낮아지고, 피해량이 소리에 더하는 값도 1/3로 감소



06월 26일

총기 개조 부품의 무게/부피 감소가 실제로 반영됨

• 접이식 개머리판처럼 총을 작게 만드는 부품이 제대로 작동함

• 너무 많이 달아도 총 무게/부피가 원래의 1% 아래로 내려가지 않음



난민센터 파블로 누녜스 대화에서 진행 안 되는 기지 가입 질문 삭제



크리스 이셔우드의 배리 구출 퀘스트 오류 수정

• 미고 정찰탑 목표 층 정보가 맞아 퀘스트 시작 에러가 나지 않음



구버전 세이브의 파이프 라이플 레시피 오류 수정

• 예전에 배운 .22/.308 파이프 라이플 레시피가 로드 에러를 내지 않음

• 새 루티 SMG 레시피도 정상적으로 사용 가능



쌀과 파스타가 더 큰 양으로 나옴

• 스파게티, 마카로니, 라자냐는 기본 8개 묶음으로 약 500g

• 쌀은 기본 12개 묶음

• 식당/집에서는 1~8개 랜덤



에어컨 같은 불투명 가구가 시야를 제대로 막음



공중에 떠 있는 차량 안에서도 제작 재료를 가져다 쓸 수 있음

• 비행선 좌석/바닥에 둔 재료가 제작 목록에 잡힘



06월 27일

원거리 공격 후 피해 로그가 빠지던 문제 수정

• 총을 쏜 뒤 "N 피해"와 사망 메시지가 다시 보임



먹기/사용 메뉴 커서가 방금 쓴 물건 묶음에 남도록 수정

• 같은 솜뭉치가 바닥과 인벤토리에 있어도 방금 쓴 쪽을 가리킴



군인 시체 현장에 적이 생김

• 좀비 병사 최대 2, 이성을 잃은 군인 최대 2, 좀비 하사 1이 나올 수 있음

• 다른 경우에는 TALON UGV가 남아 있을 수 있음



차량 화물칸/컨테이너 용량 10000L 제한 삭제

• 10000L보다 큰 저장 공간도 잘리지 않고 사용됨



M249 장착 TALON UGV 추가

• 장거리에서는 부정확하지만 빠르게 쏘고, 가까이 붙으면 매우 위험함

• 경찰 로봇류는 이제 초합금이 없는 경찰 로봇 차체를 남김



일부 차량 부품 타일이 사라지던 문제 수정

• 고급 3D 프린터 같은 부품 이미지가 다시 보임



냉난방 성능이 조금 올라감

• 기본 안정화 값이 1250으로 증가

• 파워아머 헬멧의 냉난방은 빠지고, 본체 냉난방은 2000으로 증가



착용한 것과 같은 종류의 아이템을 던질 수 있게 됨

• 배낭을 메고 있어도 손에 든 다른 배낭은 던질 수 있음



06월 28일



생존자 장갑 외골격에 전용 타일 추가

• 경량 파워아머와 같은 그림을 쓰지 않고 STALKER풍 외골격 모습으로 보임

• 헬멧과 방독면은 별도



케블라 덧댄 나무 방패/대형 나무 방패 추가

• 탄도 방어 20 제공

• 가죽 보강 방패보다 거추장스럽지만 철띠 방패보다는 덜 불편함

• 제작법과 타일 추가됨
