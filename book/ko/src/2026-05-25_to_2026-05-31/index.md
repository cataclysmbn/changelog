### 무반동 무기 조준 버그 수정

### 도축 중 시체가 썩어 사라졌을 때 활동이 깨지지 않음

### 위아래 층 생물을 조준하다 튕길 수 있던 문제 수정

### 음식이 든 시작 직업 선택 시 뜨던 아이템 위치 오류 수정

### 난민 센터 올드가드 의사 2, 3번째 임무 수정

- 이전 임무와 이어지도록 대사가 바뀜
- 존재하지 않는 지하 연구소로 보내던 깨진 3번째 임무 삭제

### 올드가드 의사 4번째 임무가 마이크로랩 임무로 바뀜

- 마이크로랩에서 특수 좀비 현장감독을 찾아 처치하고 기밀 문서를 회수함
- 현장감독은 쇠망치를 든 좀비 작업자를 소환함

### 아이템 이름 뒤에 상태 표시가 붙을 수 있게 됨

- 친화 로봇의 `(friendly)`, 무전기 개조 부품의 `(radio: R)` 같은 표시가 이름에 붙음
- 모드 아이템도 상태를 이름으로 보여줄 수 있음

## 05월 27일

### 아이템 이름 뒤 상태 표시가 번역 가능해짐

- `(wet)`, `(friendly)` 같은 표시를 한글패치에서 번역할 수 있음

### 냉동고 음식 표시가 `(very cold)`에서 `(frozen)`으로 짧아짐

- 냉장고나 뿌리 저장고 음식은 계속 `(cold)`로 표시됨

### 새 구역 생성과 지도 로딩 속도 향상

- 루아 지형 생성이 있는 모드, 특히 Overgrowth 같은 모드에서 체감이 큼

### 올드가드 의사 5번째 임무가 TCL 임무로 바뀜

- 화물 구역에 바리케이드를 친 수석 과학자에게서 기밀 연구소 문서를 얻어야 함
- 설득, 훔치기, 살해, 보스 처치 임무 중 하나로 해결 가능
- 보스를 잡는 쪽을 고르면 이후 수석 과학자가 Hub01 비슷한 물품을 파는 상인이 됨
- 반복 설득으로 경험치를 무한히 얻던 문제도 막힘

### 펜싱 선수 직업에 찌르기 무기 2레벨 추가

- 에페를 쓰는 직업인데 찌르기 기술이 없던 문제 보완

### 씨 스쿠터 부품을 차량에 설치할 수 없게 됨

- 배터리와 엔진 부품이 설치 메뉴에 뜨지 않음

### 일반 차량 색상이 16색으로 늘어남

- 기본 차량 색상들이 같은 확률로 나옴
- More Vehicle Colors 모드는 각 색상마다 더 많은 변형을 고름

### 40mm 유탄 상향

- 40x46mm, 40x53mm HEDP는 작은 강한 폭발과 파편 반경 7을 가짐
- 고속 40mm 유탄은 파편 관통력이 더 높음
- 급조 HE 유탄은 정식 HE보다 피해와 반경이 낮음

### 84mm 무반동포탄 상향

- HE탄은 파편 피해와 장갑 대상 피해가 올라감
- HEDP탄은 명중 피해와 장갑 대상 성능이 좋아지고, 작지만 강한 폭발을 냄

## 05월 28일

### 비글 UGV가 장거리 대전차 미사일을 쏨

- 차량을 상대로 멀리서 부정확한 152mm 대전차 미사일을 발사함

### 요리 실력이 높을수록 직접 만든 음식의 기분 보너스가 좋아짐

- 요리 레벨당 즐거움이 5%씩 늘어남
- 맛없는 조리 음식의 페널티도 덜 심해짐

### 날개 달린 비행선 경고가 덜 뜸

- 공회전 양력이 무게보다 큰 비행선은 날개 조작 경고를 띄우지 않음
- 일반 비행기는 필요한 경우 그대로 경고함

### 연구소 입구 생성 문제 수정

- 1층 포탑이 다시 나오고, 바닥도 정상 타일로 생성됨

### 새 시작 직업 3개 추가

- 폭도: 몰로토프 몇 개, 급조 방어구, 폭도 마스크를 들고 시작
- 육군 보병: 시간 이상 시나리오 전용, M1 개런드와 여분 클립을 들고 시작
- 돌연변이 무리 우두머리: 늑대 돌연변이로 시작하고 애완 늑대 3마리를 데리고 있음

### 일부 직업 시작 장비와 나이 범위 조정

- 군 관련 직업에 17~35, 20~40, 장군 30~62 같은 나이 범위가 붙음
- 기본 생존자는 성냥 대신 일회용 라이터를 받음
- 관광객은 티셔츠 대신 하와이안 셔츠를 입음

- 일부 레시피는 요구치가 2배~3배 이상 올라가 초반 제작이 어려워짐

### 밀수선 스폰이 줄어듦

- 호수와 강에서 덜 나옴

- 극단적 대사 변이가 빠짐

- 유전적 혼돈이 빠지고, 빠른 회복은 랜덤으로 붙을 수 있음

- 운동 기술이 2에서 5로 증가

### 새 직업 `세계 최고의 운동선수` 추가

- 10 운동, 2 투척, 2 근접, 2 회피를 가진 10종 경기 우승자 컨셉 직업

### 연구소 잠긴 문을 여는 일회용 문 해제 코드 추가

- 연구소 안에서 드물게 찾을 수 있고, 잠긴 문 하나를 열 수 있음
- 과학자 관리자 좀비가 확정으로 드랍함
- 관리자 사무실이 드물게 생성되며 관리자 좀비가 보장 스폰됨
- 연구소 단말기 첫 로그인 해킹 난이도는 1로 낮아짐
- 무기고 방 비중은 줄어듦

### 야생 인간이 던지는 돌이 훨씬 덜 정확해짐

- 분산도가 150에서 6000으로 올라감
- 이제 총 수준 명중률이 아니라 평범한 사람이 돌 던지는 정도로 빗나감

### 장시간 대기와 활동 처리 속도 향상

- 밀폐 용기는 부패 진행을 막음
- 몬스터나 아이템이 많은 곳에서 턴 처리 시간이 줄어듦

### macOS에서 SQLite 저장 중 튕길 수 있던 문제 수정

- V2 지도 저장을 여러 스레드가 동시에 처리할 때 저장 파일 접근을 안전하게 바꿈

### 비트맵 폰트 로딩 문제 수정

- 16x16 비트맵 폰트를 18x18 게임 타일에 맞춰 써도 튕기지 않음
- 회색 글리프도 색상에 맞게 섞임

### 40x53mm 유탄 변환 키트 추가

- M79, M32 MGL에 장착하면 40x46mm와 40x53mm를 둘 다 쓸 수 있음
- RM802 유탄발사기는 기본으로 두 탄종을 모두 장전 가능
- 군용 총기 개조품 목록과 고급 제작 레시피에 추가됨

### 큰 도시는 도시답게, 작은 도시는 마을답게 생성됨

### `정말 재수 없는 날`과 `불타는 건물` 시작 지점의 화재가 복구됨

- 원래 의도대로 불타는 건물 안에서 시작하며, 불과 연기가 생성됨
