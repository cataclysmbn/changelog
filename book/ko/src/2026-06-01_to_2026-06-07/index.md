# 밝밤) 6월 1일 ~ 6월 7일 패치

## 06월 01일

### 일부 시작 지점에서 게임 불러오기 때 바로 튕기던 문제 수정

- 판자 친 시작 지점 관련 변경은 일단 이전 상태로 되돌림

### CVD 장치로 다이아몬드 코팅한 근접무기에 방어구 관통이 붙음

- 베기/찌르기 피해의 35% + 10만큼 관통 추가
- 생체공학 무기는 피해의 50%만큼 관통 추가
- 야생 블랙옵스 생체병도 단분자검 설정에 맞게 관통 공격을 함

### 구급상자가 일반/고급으로 나뉨

- 일반 구급상자는 붕대, 거즈, 소독제, 의료용 테이프, 책자 위주
- 고급 구급상자는 기존 구급상자에 있던 추가 물품을 들고 나옴
- 기존 구급상자 스폰 일부가 고급 구급상자로 바뀜

### 응급처치 물품 밸런스 조정

- 식염수는 안약 대신 깊은 물린 상처를 50% 확률로 처치
- 지혈제 성공률 90% → 99%
- 임시 붕대 성공률 90% → 80%
- 솜뭉치 효과 75% → 50%
- 임시 소독제, 타임 오일, 부들 젤리는 성공률 80%로 통일
- 식염수로 식염수 안약을 만드는 제작법 추가

### 군 의무병 시작 직업 추가

- 응급처치 중심 스킬과 RX12 같은 드문 의료품을 들고 시작함

### 의료 앰풀과 스팀팩 모듈 제작법 추가

- 시험관, 식염수, 의료 재료, 나노물질이 필요함
- 기밀 화학 참고서와 리브텍 설계 바인더에서 배움

### 무작위 무기와 생존자 장비를 받는 도박형 시작 직업 추가

### 강철 참호 갑옷과 헬름이 생존자 좀비와 일부 도적 장비에 추가됨

- 스폰 비중은 대응되는 고철 갑옷의 1/3 정도
- UDP 타일에서 고철 갑옷처럼 보이던 문제도 고유 스프라이트로 바뀜

### 강화 전기 모터가 초합금이 아니라 강철 재질이 됨

- 제작 후 분해해서 초합금을 무한히 얻는 꼼수 차단
- 수리와 분해 결과도 강철 기준으로 바뀜

### 새 줍기 메뉴에서 탄약 같은 충전식 아이템을 원하는 수량만큼 제대로 줍게 됨
